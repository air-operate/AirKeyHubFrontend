# AirKeyHub 📱

Mobile app for smart key sharing and property access control, built with **React Native**.

---

## 🚀 Prerequisites

| Tool             | Minimum Version       |
|------------------|------------------------|
| Node.js          | 18 LTS                 |
| React Native CLI | 10                     |
| Xcode            | 15 (macOS only)        |
| Android Studio   | Flamingo / Hedgehog    |

---

## ⚡ Quick Start

```bash
git clone https://github.com/airkeyhub.git
cd airkeyhub
npm install  # or: yarn


Running the app:-

iOS:-
cd ios
pod install    # one-time setup
cd ..
npx react-native run-ios

Android:-

npx react-native run-android


iOS (App Store)
Open ios/AirKeyHub.xcworkspace in Xcode.

Go to Signing & Capabilities:

Use match credentials for airkeyhubltd@fatafati.net

General → Identity
